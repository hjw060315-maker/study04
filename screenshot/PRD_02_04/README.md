# PRD_02_04 캡처: AI 모델 실패를 정직하게 보고하는 화면

이 캡처는 실제 모델이 실패한 장면이 아니라, **모델 호출만 일부러 실패시키는 시험용 실행 파일로 앱을 띄워서** 찍은 것입니다
(앱 코드는 그대로이고, `ingredients.chat` / `recipes.chat`만 429·404·403·형식 오류를 내도록 바꿨습니다).
실패했을 때 화면이 어떻게 보이는지를 확인하는 용도입니다.
